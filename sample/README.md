# Sample Financial Models

To test the Financial Model Mapper, do not commit real or confidential client data to this repository.

You can obtain or generate safe sample financial models from:
1. Public financial model templates from corporate finance educational portals (e.g., Macabacus, CFI, or Wall Street Prep free template libraries).
2. Public SEC 10-K / 10-Q financial statement data exports from EDGAR.
3. Creating a standard workbook in Microsoft Excel or Google Sheets with sheets named `IS`, `BS`, or `CF` containing financial line items (Revenue, Cost of Goods Sold, Net Income, Cash and Cash Equivalents, etc.) and saving as `.xlsx` or `.xlsm`.
